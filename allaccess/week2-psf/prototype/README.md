# ქაღალდის პროტოტიპი (PSF, ნაწილი 3)

**რა არის:** ALL access-ის 5 ეკრანის დაწკაპუნებადი „ქაღალდის“ პროტოტიპი (`index.html`, ერთი ფაილი, ინტერნეტი არ სჭირდება; იკონები: `vendor/fontawesome`). სახელები და რიცხვები გამოგონილია. ტესტის შედეგები ჯერ არ არის: ტესტი 3 რეალურ ტესტერზე უნდა ჩატარდეს (HR/ადმინისტრაციის მენეჯერები ცვლებით მომუშავე კომპანიებიდან, არა მეგობრები).

**ამოცანა ტესტერისთვის:** „დახურე ოქტომბერი ქირურგიული განყოფილებისთვის: 14 ოქტომბრის ღამის ცვლა გაიცვალა (ნინოს მაგივრად მაკომ იმუშავა), ერთი ექთანი 3 დღე ავად იყო. ბუღალტერს გაუგზავნე ტაბელი.“

## როგორ ჩავატაროთ ტესტი

1. გახსენით `index.html` ბრაუზერში (ლეპტოპი ან ტელეფონი). ამოცანა ჩანს ყვითელ ბარათზე „ამოცანა ტესტერისთვის“.
2. ტესტერს მიეცით ამოცანა და **არაფერი აუხსნათ**. უბრალოდ დააკვირდით: სად ჩერდება, რას ეძებს, რას ამბობს ხმამაღლა. კითხვაზე უპასუხეთ: „როგორ მოიქცეოდით რეალურად?“
3. ფასილიტატორის კლავიშები: **L** ჟურნალი (ყოველი კლიკი დროით, ამოცანის 5 ნაბიჯის სტატუსი, `.txt` ჩამოტვირთვა), **R** ყველაფრის გადატვირთვა შემდეგი ტესტერისთვის, **T** ამოცანის ბარათის დამალვა/ჩვენება.
4. ყოველი ტესტერის შემდეგ ჩამოტვირთეთ ჟურნალი, შემდეგ დააჭირეთ R-ს.
5. რას ვაკვირდებით: პოულობს თუ არა, სად ჩაწეროს გაცვლა; ენდობა თუ არა რიცხვებს Excel-ში გადამოწმების გარეშე; კითხულობს თუ არა „ამას ვინ შეიყვანს, მე თუ ექთნები?“.
